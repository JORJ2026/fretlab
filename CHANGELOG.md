# FretLab changelog

## Unreleased

- Jam Band timing, round 2: hidden Timeline/Piano/Jam-tab/Bass panels no longer re-render while playing; the section list is cached during playback; fretboard and bass-neck note flashes no longer force a layout per note; the bass diagram updates only when its settings change. Result: 0 late notes at normal speed and at 4x CPU slowdown.

- **Root / Scale controls moved under the Instrument bar.** The Controls card content (Root, Spelling, Scale, Play scale, Library, Loop, … and the matching rows in the Chords, Intervals and other modes) now sits directly under the Instrument bar inside the Fretboard card; the empty Controls card is hidden.
- **Jam Band playback no longer stutters.** The "name every unnamed field" accessibility pass (UX lab) re-scanned every form field on the page, and cloned each field's parent element, every half second while anything changed on screen. On the Jam Band page that blocked the main thread for up to 0.2 s at a time (about 20% of all CPU), which is what made the backing track choppy. Each field is now looked at once. On a simulated 4x slower computer the old build scheduled 24 of 59 notes late (up to 0.4 s); the new build scheduled none late. The Jam Band also schedules half a second ahead instead of 0.3 s, so a brief stall is not heard.
- **New defaults for the Show row:** only "Fretboard diagram" is ticked; Tab · one octave, Tab · live, Tab · Jam Band, Piano, Bass fretboard and "Show tab under the diagram" start unticked. (The choice is stored under a new name, so everyone starts from these defaults once.) Bass neck work is skipped while it is hidden.
- **Strings bar:** under the Instrument bar, every string has its own tuning arrows and first–last fret boxes (the same ranges as Strings & ranges…, which stays for adding and removing strings). The legend, tap-a-fret line, Position, Position window, Fret window, picture buttons, Show/Practice pattern row and Tune row now sit directly under Play / Stop / Diagrams only, above the fretboard.
- **Desktop and Android packages.** `FretLab-12-Windows.zip`, `-Mac.zip`, `-Linux.zip` (small Go launcher in `desktop/`: serves the site on 127.0.0.1 only, opens the browser, quits itself after the last tab closes, reuses one fixed port so settings are kept) and `FretLab-12-Android-Project.zip` (`android/`: the app now serves its pages over a private https address from the bundled assets instead of `file://`, so downloads, the guide and workers behave like the website). The Android project could not be compiled in the build environment.
- **Bass fretboard checkbox.** The Show row under the instrument picker has a new "Bass fretboard" tick box that shows or hides the bass neck under the guitar neck (remembered between visits). The Bass neck button, the Navigate menu and the phone dock turn it back on if it was hidden.
- **Release hygiene pass.**
  - Licences: `THIRD-PARTY-NOTICES.txt` now lists every bundled library with its licence (SheetJS Apache-2.0; jsPDF, html2canvas, JSZip, docx and Tone.js MIT; DjVu.js GPL-2.0-or-later). The MIT and Apache texts are in `licenses/`. FretLab itself is now GPL-3.0-or-later (`LICENSE`), which fits every bundled library including DjVu.js.
  - Fixed pages: `original/dummy.html` and `chord-progressions-standalone.html` no longer request the missing `theory-decks/` scripts (the DAW presets they added are simply absent). `andalusian.html` and `andalusian-standalone.html` now open the Cadence Map. `site-map.html` no longer links to Theory Decks pages that are not in this package.
  - One name and version: the Beta, the single-file downloads and the Jam Band page now say "FretLab 12" instead of "JackRoseGuitar"; the README, feature reference, publishing guide and start page say 12. (The Android bridge name `JackRoseGuitarAndroid` is unchanged because the Android project expects it.) The README now says which downloads are in this folder.
  - Code: 19 shadowed duplicate function definitions (17 names) removed from the Beta; the last definition was always the one that ran, so behaviour is unchanged. `new Function` is gone: the MP3 encoder runs in a Blob worker, with a Blob script as the fallback.
