🪟 Windows

For Windows 10 and 11, on 64-bit Intel/AMD or ARM.

  1. Unzip the file.
  2. Run Install-Windows.bat to add Desktop and Start-menu shortcuts, or run FretLab.exe directly.
  3. If SmartScreen appears, choose More info → Run anyway.
Download for Windows

🍎 macOS

One app for Apple Silicon and Intel Macs.

  1. Unzip the file and run Install-Mac.command, or drag FretLab.app to Applications.
  2. If macOS blocks it, right-click the app, choose Open, then Open again.
Download for Mac

🐧 Linux

For 64-bit Intel/AMD and ARM.

  1. Unzip the file and run ./install-linux.sh to add a menu entry, or run ./fretlab.
Download for Linux

🤖 Android

An Android Studio project that builds an APK. The app has no internet permission at all.

  1. Open the folder in Android Studio and choose Build → Build APK(s).
  2. Or, without building, open this website once in Chrome and choose Install app.
Download the Android project

📱 iPhone and iPad

Install it straight from this website.

  1. Open this site in Safari.
  2. Tap Share → Add to Home Screen.
  3. Open it once while online, then it works offline.
